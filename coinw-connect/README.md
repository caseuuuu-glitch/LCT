# CoinW Connect · Buy Now

Interactive Buy Now prototype + PRD for CoinW Connect.

- `index.html` — responsive Web/Mobile interactive prototype with an in-page PRD drawer
- Main flow: Asset/Fiat → Payment Method → Buy Now → Sign up/Login → Quote → Review → Order
- Includes: Card / Apple Pay / Google Pay / Third-party fallback, Popular assets, How to Buy, SEO growth placeholders, routing/KYC/order/API requirements
